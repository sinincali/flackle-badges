# Flackle Badges 🏆

A collection featuring every badge on Flackle!

Flackle badges are achievements that show up on your profile. They are given out by Flackle for things like supporting the platform early or subscribing to Flackle Beyond. This collection lists every badge, what it looks like, and how to get it.
