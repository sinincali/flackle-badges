# Contributing

1. Put the badge icon in `assets/` (SVG preferred, PNG is fine), named in kebab-case, e.g. `bug-hunter.svg`.
2. Add a row to the right table in `README.md`: title, badge image, whether it's obtainable, and how it's earned.
3. Add a line to the **Badge Change Log**.
4. Open a pull request with a source (screenshot or announcement) for the badge.
